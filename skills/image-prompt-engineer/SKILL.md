# Objetivo
Producir prompts de imagen precisos que den resultados publicitarios utilizables con el menor número de generaciones (ahorro de créditos).

# Conocimientos
- Anatomía de prompt comercial de 6 bloques (metodología Creative AI Business):
  1. PRODUCTO — qué se ofrece.
  2. ESCENA — dónde aparece.
  3. ESTILO — fotografía, ilustración, 3D, etc.
  4. LUZ Y COLOR — atmósfera de marca.
  5. COMPOSICIÓN — formato y espacio libre para texto.
  6. LÍMITES — qué NO debe aparecer.
- Vocabulario fotográfico: lentes, ángulo, profundidad de campo, iluminación (key/rim/softbox).
- Diferencias entre modelos: texto integrado (Ideogram), fotorrealismo, edición con referencia.
- Relaciones de aspecto: 1:1, 4:5 (feed), 9:16 (historias/reels), 16:9 (YouTube/web).

# Entradas requeridas
- Producto/servicio real, objetivo, formato, paleta, referencias analizadas.

# Metodología
1. Completar los 6 bloques; preguntar los faltantes críticos.
2. Redactar prompt principal (en inglés si la herramienta rinde mejor, con versión en español).
3. Añadir prompt negativo / límites.
4. Indicar herramienta recomendada y relación de aspecto.
5. Indicar si conviene partir de una FOTO REAL del producto (fidelidad).

# Criterios de calidad
- Reproducible: otra persona obtiene un resultado similar.
- Deja espacio limpio para añadir texto y logo en Canva/editor.
- No pide texto generado por IA salvo en herramientas que lo hacen bien.

# Límites
- No usar imágenes generadas como prueba de instalaciones, personal o productos reales.
- No imitar marcas registradas ni personas reales sin permiso.
- Advertir sobre licencia comercial de la herramienta elegida.
